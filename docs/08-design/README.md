# 08｜设计与原型验收

本目录用于把 AI 设计稿、产品原型和真实页面放在同一条验收链路中。完整功能说明和原型中明确的业务逻辑决定功能边界，AI 设计稿主要提供视觉和交互参考，当前代码和 API 决定“已实现”结论。

## 当前已对齐范围

代码已包含薄荷绿视觉令牌、公共页头、账单行、四项底部导航、金额键盘、账户/日期/备注弹窗、首页、日历、资产、账单详情、账户详情、我的和帮助页。日历页上半部分固定，选中日期的账单记录在独立滚动区域内浏览；资金账户和信贷账户详情固定账户信息与五项筛选按钮，日期/笔数和流水在下方独立滚动，日期分组标题按组吸顶并由下一组替换。账单详情、账户详情与新增记账使用相同的紧凑顶部导航规格。底部导航应为四项等宽的连续白色底栏，按钮无独立卡片边框/圆角/阴影，选中项仅保留图标薄荷绿背景。统计、分类、凭证/OCR、预算、周期记账、多人账本、导出/删除数据等仍必须显示未开放。

运行时金额展示统一使用 app/src/components/MoneyDisplay.vue，金额区域只展示金额数值和必要的正负/文字前缀，不渲染钱币图标；覆盖首页、日历、资产、账户详情、账单详情、退款、还款、记账和交易列表。输入框也不附加 ¥。

## 当前未闭环范围

微信自动登录前端分支与当前后端路由不匹配；微信头像选择器未接入；真实后端数据、数据库迁移、对象存储和微信开发者工具验收未由源码或构建证明。现有审计文档曾引用截图证据，但当前工作区未找到对应 `app/tests/evidence/*.png` 文件，因此本次不能把逐区域视觉截图写成可复核 PASS。

## 验收要求

核对页面是否遵循四项底部导航、首次使用流程、H5 登录/注册入口和帮助页未开放提示；核对 loading、空态、错误态、重试、表单校验和成功后的刷新行为；核对 320px、375px、414px 无横向滚动。视觉验收必须记录实际页面、环境、截图路径或可复现路径，不能以“构建成功”替代设计和交互验收。
