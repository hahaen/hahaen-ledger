# 哈记账文档体系

## 当前权威规范

- `00-overview/`：产品边界、首版开放范围和文档使用说明。
- `01-architecture/`：模块架构、认证、金额与时间口径。
- `02-database/`：Flyway、Schema、表分类和数据库审计规则。
- `03-api/`：接口契约、错误码和写接口约束。
- `04-frontend/`：页面、状态、平台兼容和设计实现规范。
- `05-operations/`：配置、DEV、部署、Redis、MinIO、日志和排障。
- `06-security/`：认证、权限、IDOR、敏感信息和文件安全。
- `07-testing/`：测试、构建、运行和证据要求。
- `08-design/`：需求/原型/设计稿逐页验收记录。

## 阶段审计与历史变更

- `09-audit/` 只记录阶段审计、验证矩阵和证据，不替代当前规范。
- `10-iterations/` 只记录重要变更的原因、设计、命令、验证和回滚。

根目录的完整功能说明、AI 设计稿和原型是需求事实来源；旧版扁平文档仅作为迁移期间的历史参考，新增内容不得继续写入旧路径。
