# 数据表分类说明

本文件用于判断一张表应使用哪套公共字段，以及审查其是否被错误地套用了另一套模型。

## 主表

主表代表可独立管理的业务对象，例如用户、账本、账户、账单和文件元数据。主表继承 `BaseAuditEntity`，包含创建人、更新人、删除人及对应快照名称等完整审计字段。主动删除时必须写入删除标识、删除时间、删除人和可获得的删除人名称。

## 关联表

关联表只表达两个或多个主对象之间的关系，不承载独立生命周期或完整操作审计。它使用 `created_at` 和 `deleted`，不机械增加主表的创建人、更新人等字段。关联查询必须同时带上关联两侧的有效性和当前用户/账本归属条件。

## 审查清单

设计表时依次确认：表是否有独立详情和生命周期、是否需要主动删除、是否承载业务字段、是否会被单独授权访问、是否与当前账本隔离。无法证明是纯关系的表，不应为了减少字段而简单归类为关联表。
