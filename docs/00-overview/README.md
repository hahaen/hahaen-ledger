# 00｜项目概览

本目录回答“哈记账是什么、首版做什么、明确不做什么”。它是产品和工程协作的共同入口，帮助开发、测试和审计在进入具体技术文档前建立相同的范围认知。

## 应说明的内容

- 产品面向微信小程序，同时保留 H5 构建能力。
- 当前模型是单用户、单账本、人民币记账；核心业务包括支出、收入、转账、退款、信贷还款、账户资产以及按月/按日查看。
- 底部导航固定为首页、日历、资产、我的。
- 统计、分类、凭证/OCR、预算、周期记账、多人账本、多币种、支付平台同步、导出和删除数据等首版能力必须标明未开放。

## 使用方式

需求评审先引用本目录确认范围；发现新需求超出首版边界时，应先建立迭代档案并明确是扩展、替换还是暂不开放。这里不放具体 SQL、接口字段或测试执行结果，那些内容分别归入数据库、API 和审计文档。
