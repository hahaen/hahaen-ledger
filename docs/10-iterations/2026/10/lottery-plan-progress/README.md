# 定投卡片进度与预计提醒

2026-10-30。初始工作区与暂存区干净，main跟踪origin/main，HEAD37c04d2。

## requirement

彩票定投卡片直接显示当前实际购买批次的已开奖、剩余期数、预计下次提醒时间。沿用现有到期提醒，不扩展提前续买。

## design / frontend

卡片累计成本/奖金保留；追加“本批”进度及下一提醒区，沿用薄荷色细分隔与12px辅助文字，窄屏可换行。时间显示北京时间日期“晚开奖后”，避免承诺具体投递分钟。暂停/结束/无批次/已受理/到期等待/未知日期明确区分。

## database / api / backend

不改Schema、Entity和写入流程，无Migration或运维SQL。列表及计划详情新增progress只读对象：batchId/startIssue/periods/drawnCount/remainingCount/estimatedReminderDate/reminderState。按当前用户最新购买批次查询，所有个人查询限定user_id并排除逻辑删除。已开奖按draw_id判定，奖金待核实也算已开奖。

预计日期以该批次已知官方开奖日期为锚点，未知尾部按DLT周一三六、SSQ周二四日推算。无批次已知日期时仅对同年度未来起始期从本地最新官方期次估算；跨年度无法确认起始期则不猜。估算不写入期号/任务/事件，提示休市、延期及同步延迟会调整。已知官方日期后随读取更新。

依据：[体彩规则](https://m.lottery.gov.cn/ksjz/m/yxgz_dlt/)、[上海福彩开奖页](https://cp.swlc.sh.cn/)。
