# 主导航页面后台刷新与闪烁修复（2026-10-01）

- requirement：修复首页、日历、资产、物品切回页面时内容闪烁。
- design：区分请求进行中与首次没有数据；同会话、同月份/日期/筛选切回时保留已有内容（含空状态）并后台刷新，首次或上下文切换保留加载与错误反馈。
- database / api / backend：无变更；保留现有当前用户接口、金额计算和写入刷新。
- frontend：调整四页状态及模板，保护并发请求、切换条件与会话清理；首页下拉指示只用于主动刷新。
- testing：真实页面脚本与编译模板回归，先复现慢请求切回闪烁，再覆盖更新、失败、空状态、月份/日期/筛选切换和会话变化。
- commands：见 [真实执行记录](08-commands.md)。
- verification：必需验证 PASS；真实页面脚本与模板隔离验收 PASS，客户端整体 PARTIAL，微信工具/真机及真实用户切换 NOT_RUN（补充）。见 [验收记录](09-verification.md)。
- rollback：回退本轮前端、测试和文档提交，无数据库操作。
