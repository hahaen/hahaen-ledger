# 后端

TodoPlanning统一计划字段校验、编辑原计划判断与首项计算，preview和create/edit均使用正式TodoRepeat/TodoSchedule；预览最多3项，完成后不虚构后续日期。TodoService原计划不变时使用editContent/editPendingContent，仅更新当前用户未删除规则及未完成项的标题、备注、提醒及审计；保留发生项ID、时间、周期游标、完成历史和投递记录。重排仍在同一事务替换未完成项并记录幂等。

新增/重排按时间模式允许今天的开始日期，已过去的时刻跳到下一匹配日，不补生成过去项，仍保留所选日期为周期起点。其余模式实际首项须晚于现在；原计划不变时允许保留逾期项。无数据库结构变更。
