# `flyway-v3-repair`｜Flyway 历史迁移修复

## 迭代目的

本迭代记录一次 Flyway 版本或校验问题的修复背景，用于说明修复是通过新增迁移、调整配置还是修正环境状态完成，并防止以手工 ALTER 代替可追溯变更。

## 应记录的重点

应列出问题版本、数据库当前状态、影响范围、修复迁移、执行前数据检查、Flyway history 结果和失败时的恢复步骤。若历史迁移已在共享环境执行，不得直接修改或删除原文件。

## 当前档案状态

当前工作区未保留本迭代明细文件；不能从目录名称推断 V3 已执行或修复成功。应以实际 Flyway 日志和 `information_schema` 对照作为结论。
