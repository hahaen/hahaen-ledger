# 06｜前端

已完成的前端实现：

- 首页：月度切换、概览、按日分组、空/失败重试、详情跳转和保存后刷新。
- 日历：星期标题、6 行网格、跨月日期样式、今日/选中态、标记、单日汇总、列表和竞态保护。
- 资产：总资产/负债/净资产、资金/信贷分组、表单校验、账户详情、流水筛选、还款、删除确认。

首页、日历、资产和必要关联页均只通过 `app/src/utils/api.ts` 请求；Store 的首页/账户刷新和日历页面使用请求序列保护，保存/还款/删除按钮具备禁用或确认状态。`pnpm run typecheck`、`pnpm run build:h5`（注入本地 API 地址）和 `pnpm run build:mp-weixin` 已通过。

未完成人工设计验收：尚未在微信开发者工具和 320/375/414px 设备截图逐区域对照，真实登录态、真实账务数据和小程序交互仍需外部会话。
