# `bottom-nav-design-alignment`｜底部导航设计稿对齐

## 迭代目的

修复 H5/uni-app 底部导航按钮被平台默认样式渲染成四个独立圆角卡片的问题，使其与设计稿一致：整块白色底栏、四项等宽、无按钮边框与阴影，仅当前项图标保留薄荷绿色背景。
