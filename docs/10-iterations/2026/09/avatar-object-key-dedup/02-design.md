# 设计

`avatar_file_url` 的语义为 `app_file.object_key`，不是 URL。预览继续由服务端按当前配置生成短时签名 URL。浏览器用 Web Crypto 计算 SHA-256；服务端以用户、头像类型、摘要、`READY` 和未删除状态查询可复用记录。确认上传时，服务端重新流式计算 SHA-256，并核对大小、声明 MIME 和文件头。

去重范围限定当前用户，避免跨用户复用文件元数据产生归属和删除语义冲突。

兼容历史数据：若当前头像在旧版本创建且 `file_hash` 为空，首次选择同一图片时服务端读取该当前对象并计算摘要；匹配后回填摘要并直接复用，不创建新对象。
