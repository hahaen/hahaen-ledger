# 测试

后端新增 `AppFileServiceTest`，验证同用户同 SHA-256 的 READY 头像不调用 `insert`，也不在文件上传阶段更新当前头像；`ProfileServiceTest` 验证仅资料保存携带自己的 READY 头像文件 ID 时才写入对象 Key。还需执行 Maven 单测、前端类型检查、H5/小程序构建及真实依赖环境验证。

该测试另覆盖历史当前头像的摘要为空时，服务端从对象流计算摘要、回填元数据并复用，而不是创建新文件记录。

前端回归覆盖文件名和浏览器 MIME 为 PNG、实际 JPEG 文件头时，上传申请声明 `image/jpeg`，以匹配服务端内容校验。

前端回归额外验证个人中心头像按钮动态创建原生 file input，设置允许的图片类型并复用同一个选择器；不再依赖会被 uni-app 编译改写的模板输入框。

前端回归覆盖选择新头像后仍显示旧头像、保存请求携带暂存的 `avatarFileId`，且仅资料保存成功后才切换预览。
