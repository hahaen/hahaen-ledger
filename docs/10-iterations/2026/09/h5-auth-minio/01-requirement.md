# 需求

## 目标

- H5 用户可以使用账号、密码和图形验证码注册。
- H5 用户可以使用账号、密码和图形验证码登录，并获得 Sa-Token 会话。
- 密码通过浏览器 Web Crypto 使用服务端 RSA 公钥加密传输，服务端只保存 BCrypt 哈希。
- 登录失败不泄漏账号是否存在，并写入登录审计日志。
- 登录用户可以通过短时效预签名 URL 上传和预览头像，文件元数据写入 `app_file`。

## 约束

- 所有文件接口必须校验当前 Sa-Token 用户与文件归属。
- 不向前端返回 MinIO 密钥、永久 URL 或对象 Key 以外的存储凭证。
- 当前只开放 `AVATAR`；`TRANSACTION_ATTACHMENT` 等账本关联类型待对应业务表完成后实现。
