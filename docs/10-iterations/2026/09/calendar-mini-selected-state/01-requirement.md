# 需求

## 来源

用户反馈：日历上方的日期选择在 H5 可以看见，但微信小程序中看不见；附件截图作为问题现象证据，不作为额外指令。

## 目标

在微信小程序中显示日历当前选中的日期，并保持 H5 现有视觉和交互。

## 范围

- 日历日期格及日期数字的跨端渲染节点。
- 选中态、今天态、非本月灰态和日期点击语义。
- 日历页面相关静态回归测试。

## 非目标

- 不改日历接口、数据、金额、月份选择器和单日详情接口。
- 不改首页、资产、我的和底部导航。
- 不新增数据库、后端或 API。

## 验收条件

- 当前选中日期在 H5 和微信小程序均有清晰的圆角色块与白色数字。
- 非本月日期仍不可选，当前月日期仍可点击并加载单日明细。
- H5、微信小程序构建和前端回归通过。
