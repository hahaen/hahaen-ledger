# 需求

## 来源

- `AGENTS.md`：数据库公共字段、金额、逻辑删除、权限、事务和 Flyway 规则。
- `README.md`：单用户、单账本、人民币定位及 Flyway 运行方式。
- `哈记账微信小程序_完整功能说明.md`：Transaction、RefundRecord、有效金额及还款规则。
- `哈记账微信小程序_AI设计稿需求.md`：新增/编辑记账、账单详情和退款交互。
- `哈记账小程序_原型设计稿/README.md`、`app.js`：四类类型、字段交互、退款记录和示例状态。

## 本次目标

设计账单明细主表和必要的退款记录表，支持唯一编号、四类账单字段规则、原始金额/有效金额、独立多笔退款、逻辑删除和按用户/日期/类型/账户查询；单账本不重复保存账本 ID。

## 非目标

不修改 Entity、DTO、VO、Mapper、Service、Controller、前端页面、TypeScript、账户余额业务或账本主表；不新增退款账单类型，不保存 JSON/拼接字符串。
