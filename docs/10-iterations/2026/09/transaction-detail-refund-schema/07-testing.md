# 测试

## 已执行范围

本轮执行静态 Migration/文档检查、版本和表名冲突检查、敏感信息扫描；真实 MySQL/Flyway 行为需以 `08-commands.md` 的实际输出为准。

## 后续数据库验收用例

- 四种类型的账户字段组合及转出/转入不能相同。
- 原始金额保持不变，当前金额按多笔有效退款递减。
- 退款累计等于原始金额后不能继续退款。
- 逻辑删除的账单和退款不参与累计；删除退款恢复有效金额。
- 转账/还款退款被 Service 拒绝。
- 唯一账单编号、退款编号和幂等键冲突被拒绝。
- 并发退款以原账单行锁串行化，不发生超额退款。

当前未修改业务代码，因此上述运行时业务用例为 `NOT_RUN`。
