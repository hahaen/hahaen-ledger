# 需求

## 来源

- 用户本轮需求：完成“哈记账小程序_原型设计稿”的 H5 我的页，后续再补微信小程序。
- `哈记账微信小程序_完整功能说明.md`：我的、关于与帮助、退出登录和头像状态。
- `哈记账小程序_原型设计稿/app.js`：原型中的 mineView、aboutView、隐私说明和反馈交互。

## 目标

1. 我的页按原型还原个人卡片、累计记账天数、更多入口和退出登录。
2. 累计记账天数由当前用户 `app_user.created_at` 计算，不能使用前端固定示例值。
3. 关于与帮助页还原快速开始、FAQ、隐私说明、暂未开放、反馈预留和版本信息。
4. H5 头像点击选择文件，上传到 MinIO，并刷新当前头像。
5. H5 退出登录清理服务端会话和本地令牌，但保持在我的页；头像区域切换为“登录”状态。

## 非目标

- 本轮不实现微信小程序头像选择器和微信头像授权。
- 不开放数据导出、数据删除、反馈提交等原型中明确的暂未开放能力。
- 不新增账本或账单业务。

## 验收条件

- 已登录用户能看到服务端返回的昵称、头像状态和累计天数。
- 头像仅接受 JPG/PNG/WEBP/GIF，上传成功后可预览，权限按当前用户隔离。
- 退出登录后当前页仍显示，头像卡片出现“登录”，点击可回到 H5 登录页。
- 关于与帮助的原型内容和四条 FAQ 可见，隐私说明与反馈/暂未开放入口可操作且不伪造成功。
