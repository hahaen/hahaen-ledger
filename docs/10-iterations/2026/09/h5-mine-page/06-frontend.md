# 前端

- `app/src/pages/mine/mine.vue`：按原型补齐个人卡片、头像点击上传、累计天数、关于与帮助、退出登录和未登录状态；登录态不再显示“去授权”或“头像未授权 · 可继续使用”，头像本身直接作为 H5 上传入口。H5 通过原生文件节点触发选择，避免 uni-app 组件 ref 无原生 `.click()` 方法。
- `app/src/pages/help/help.vue`：还原快速开始卡片、四条 FAQ、隐私说明、数据导出/删除暂未开放、反馈预留和版本信息。
- `app/src/utils/api.ts`：继续作为唯一业务 API 入口。
- `app/src/utils/file.ts`：复用现有浏览器上传链路；页面仅通过文件接口获取短时效预览 URL。

微信专属选择器不在本轮 H5 实现中扩展，保留条件编译分支。
