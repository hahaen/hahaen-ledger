# 设计

## 页面状态

- `logged-in`：加载 `/api/app/user/profile`，头像通过现有短时效预览 URL 获取。
- `uploading`：头像选择器禁用，显示“正在获取头像…”或“上传中”。
- `logged-out`：不调用需要认证的个人资料和头像接口，使用默认品牌图，显示“登录”。
- `help`：独立二级页，FAQ 同时只展开一项；隐私说明使用 H5 可用的原生确认弹窗表达原型底部弹层内容。

## 后端方案

新增只读 `ProfileController`，仅取 Sa-Token 当前用户，按 `created_at` 和服务器默认业务时区计算自然日差并至少返回 1 日。头像继续走“申请预签名上传 URL → 浏览器 PUT → complete → view-url”链路。

## 关键决策

- “累计记账天数”按用户创建日期到当前日期的自然日（含创建日）计算，符合用户明确的“根据创建时间”。
- 退出登录不在 H5 调用 `reLaunch`，避免离开我的页；重新加载应用时仍由启动守卫把未登录用户送到登录页。
- 数据库不新增字段；用户表已有 `created_at`、`avatar_file_id`，文件表已有头像业务类型和 MinIO 元数据。
