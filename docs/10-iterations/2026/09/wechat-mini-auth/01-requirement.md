# 需求

## 目标

- 微信小程序启动时自动完成本地登录。
- H5 保持既有账号、密码、验证码登录和注册逻辑。
- 不从微信获取昵称、头像、手机号等非必要资料。
- 微信身份与本地 `app_user` 绑定，业务接口继续使用 `X-Auth-Token`。

## 非目标

- 不修改 H5 认证字段、密码加密和验证码流程。
- 不把 `AppSecret`、`session_key` 或 `open_id` 放入前端。
- 不新增微信用户资料授权。

## 验收

- 有效微信 code 可返回本地 token。
- 相同微信身份重复登录命中同一用户。
- 无效 code、关闭开关、微信服务异常均返回脱敏业务错误并记录审计。
- 小程序接口不接受前端传入 `open_id` 或 `userId`。
