# 需求

## 目标

根据 H5 账号登录、微信小程序自动登录、个人资料、跨端绑定和登录审计设计，建立用户主表 `app_user`、微信身份关联表 `user_identity` 及登录日志表 `app_login_log`。

## 范围

- 本次只生成 Flyway SQL Migration。
- 暂不实现 Entity、Mapper、Service、Controller、DTO/VO、前端绑定页面和测试代码。
- H5 账号与微信身份归属同一个 `app_user`。
- `login_account` 无论用户停用还是逻辑删除，均保持全表唯一。
- 记录用户最近登录 IP，并保留登录成功/失败日志。

## 原型依据

- H5 支持账号、密码、图形验证码登录/注册。
- 微信小程序自动完成微信登录。
- 用户昵称默认显示“账本主人”。
- 头像授权不是使用记账功能的前置条件。
