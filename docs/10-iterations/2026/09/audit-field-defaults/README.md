# `audit-field-defaults`｜审计字段默认值校正

## 迭代目的

本迭代用于统一数据库默认值、MyBatis-Plus 自动填充和 Java 审计实体之间的行为，重点解决创建时间、创建人、更新时间和逻辑删除标识在不同入口下不一致的问题。

## 应记录的重点

应逐项核对 `created_at` 的毫秒精度与默认值、`deleted` 的 0/1 语义、未知身份时创建人是否保留 NULL，以及 Update 是否错误覆盖创建字段。还要区分主表完整审计字段和关联表精简字段。

## 当前档案状态

当前工作区未保留本迭代明细文件；本 README 不宣称数据库、Entity 或测试已通过。真实结果应以迁移检查、Entity 对照和自动填充测试证据为准。
