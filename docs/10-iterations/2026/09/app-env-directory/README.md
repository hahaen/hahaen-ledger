# `app-env-directory`｜前端环境目录整理

## 迭代目的

本迭代用于整理 `app/env/` 的环境变量文件位置和命名约定，让通用变量、开发变量和生产变量有清晰的归属，减少把本地地址或真实凭证误带入构建产物的风险。

## 说明范围

应重点记录目录结构、example 文件的用途、被 Git 忽略的本地文件、Vite 对 `VITE_*` 变量的读取方式，以及生产构建缺少 API 地址时的失败策略。它不负责后端业务、数据库或 API 契约变更。

## 当前档案状态

当前工作区未保留本迭代的 01–10 明细文件；本 README 仅补充目录级说明，不能作为环境构建已执行的证据。实际命令和构建结果应在恢复明细后填入 `08-commands.md` 与 `09-verification.md`。
