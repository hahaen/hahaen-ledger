# 后端

`todo` 独立域：Controller 仅适配协议，Service 负责当前用户、校验、事务、幂等和状态，Mapper 负责访问。`TodoSchedule` 计算每天、每月、每隔 N 月、每年下一计划日期，锚定首次计划日，短月取月末。`TodoMaterializer` 每分钟建立未来一天的发生项，单次最多 366 项以避免停机后无界扫描；手动完成后确保下一项。`TodoReminderWorker` 对最近 24 小时到期、未完成的项按已配置渠道建投递，发送前重查；每渠道最多五次，失败退避。Bark/pushplus 固定官方 HTTPS 端点，Key 仅在请求体中使用。异常日志不输出请求体/Key。

新增系统审计路径：自动创建的发生项、投递和尝试使用集中 `SYSTEM_USER_ID`。审计填充器对已经显式填写 `createdBy` 的系统记录不再读取登录上下文；DEV 首次集成测试发现并修复定时线程无 Sa-Token 上下文错误。平台受理与设备送达不是同一概念；超时重试可能出现外部重复。
