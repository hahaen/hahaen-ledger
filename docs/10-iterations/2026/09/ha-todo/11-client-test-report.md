## 修复记录

1. 微信模拟器首次打开原生重复选择器时，编辑弹窗被遮罩误关。新增弹窗禁止点击遮罩关闭，保留取消与右上角关闭按钮；热更新后在微信模拟器验证日期/时间选择器退出仍保留编辑表单。小程序原生重复选择器的完整选值后提交未形成独立持久化证据，列为 PARTIAL。
2. H5 首次实测发现：重复事项完成后修改规则会再次产生已完成日期。后端编辑时查询该规则最后一次完成计划时间，重新生成严格晚于它的未完成项；双用户真实 DEV HTTP 集成测试新增相同锚点断言，H5 再次实际操作确认下一次保持 2026-11-30。
3. 编辑表单原先回填首次锚定时间，首次时间过去后会被“计划时间须晚于现在”挡住。现在回填下一次计划时间；标题/备注/提醒修改时后端保留原锚定日。北京墙上时间由 UTC+8 计算，避免设备本地时区改变计划日期。后端真实 DEV HTTP 断言已通过；本条修改后的浏览器交互见 C12。
4. 独立编辑页在 H5 硬刷新后没有清单页历史，保存成功后曾留在旧发生项 ID 并显示“未完成待办不存在”。现在仅当前一页确实为待办清单时回退，否则重定向清单；刷新、保存、显示新标题的实测见 C19。
5. 微信模拟器首轮实测发现待办清单和新增页页头被顶部安全区遮挡；调整这两个页面的导航偏移后复查标题完整可见。小程序开发监听进程一度只生成编辑页 JSON，重新执行 `dev:mp-weixin` 后生成 WXML/JS/WXSS 并恢复模拟器。
