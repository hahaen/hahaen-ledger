# 前端

“我的”页在通知中心下新增待办清单行，描边勾选图标沿用现有设置行尺寸和配色。清单页使用项目薄荷绿引导卡、白卡和圆角按钮；待完成/已完成显示计数。点击“新增待办”或未完成项的“修改规则”进入独立表单页，使用页面导航返回；未保存的修改返回时提示确认。表单提供日期时间、重复规则和提醒开关；完成、删除、分页和逐次提醒记录仍在清单页。编辑页按发生项 ID 从服务端重新加载本人未完成项，页面刷新后仍可回填。编辑表单展示下一次计划时间；仅修改标题、备注或提醒且计划时间与重复规则未变时，后端保留原始锚定日，避免短月发生项把每月 31 日改为 28 日；计划时间或重复规则变更则重设锚定日。过期项编辑默认北京当前时间后一小时。所有请求经 `api.ts`，变更请求失败时复用原幂等键。微信小程序页面已注册统一分享。
