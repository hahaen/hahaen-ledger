# 前端

`ledger` Store 增加 `reorderAccounts`，请求成功后刷新账户状态。资产页的资金/信贷列表按 `sortOrder` 展示；账户按钮增加 `@longpress`，长按后进入换序状态，点击同类账户完成交换，点击原账户取消。保存中的换序请求有禁用态，成功后刷新并提示。

交互微调：移除页面顶部换序提示条；用 `reorderingKind` 限制只有被长按的账户类型显示“交换”，另一类型保持箭头；“交换”文字使用 11px 和较深的薄荷绿文字色，避免过度透明。

账户行使用普通 `view` 容器，避免原生 `button` 内嵌点击控件的跨端事件冲突。换序状态下，账户行点击事件只负责空操作，只有右侧独立的“交换”控件通过 `@click.stop.prevent` 触发换序；未进入换序状态时，整行仍可进入账户详情。

资产账户名称右侧在 `includedInNetAsset=false` 时显示“不计入”角标，计入净资产的账户不显示该角标。
