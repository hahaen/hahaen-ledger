# `repayment-modal-account-picker`｜还款弹窗与账户选择

## 迭代目的

将账户详情页的还款系统弹窗改为参考稿风格，并支持在还款前选择资金账户。

## 实现摘要

- 还款主弹窗展示当前欠款、还款账户、账户余额、还款金额和操作按钮。
- 还款账户选择弹窗展示所有有效资金账户及可用余额，选中后返回还款弹窗。
- 还款账户默认不选中；还款账户和还款金额均为必填项，金额符号显示在数字右侧。
- 账户选择列表使用固定高度滚动区域，标题和内容字号按参考稿收敛。
- 确认还款直接调用既有还款接口，保留原有金额校验、事务和幂等键。
- 本次不修改数据库、API 和后端逻辑。
