# 需求

## 来源与目标

用户要求把 MinIO 新上传文件从 `avatars/<userId>/<uuid>.<ext>` 调整为按年月日建目录，并在唯一文件名中加入上传文件名。

## 范围

- 新头像对象 Key 格式：`avatars/<yyyyMMdd>/<userId>/<原文件名主干>-<uuid>.<ext>`。
- 日期使用 `Asia/Shanghai`；最终扩展名继续依据服务端已校验的 MIME 类型。
- 现有头像上传、摘要去重、预签名 PUT、完成校验、预览和删除链路保持原有契约。

## 非目标与验收

- 不迁移已有对象、数据库引用或文件记录。
- 不改变数据库结构、API 字段、认证、归属校验或 MinIO 配置。
- 验收新建对象 Key 包含 `avatars/日期/userId/文件名主干-UUID.扩展名`，日期为八位上海日期；真实 MinIO 运行验收单独记录。
