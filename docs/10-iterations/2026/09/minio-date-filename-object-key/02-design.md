# 设计

在 `AppFileService` 创建新文件记录时，使用当前用户 ID 和现有 `originalName` 请求字段生成对象 Key。对象名去除上传名末尾扩展名后追加 UUID，再追加由实际 MIME 类型确定的扩展名，避免重复扩展名或依赖不可信的上传扩展名。

上海时区日期用于日期目录，格式为 `yyyyMMdd`。Key 保留用户 ID 目录；用户归属仍由 `app_file.user_id` 和服务端当前用户过滤校验，不以对象 Key 目录代替权限判断，因此不需要迁移权限查询。

同摘要 READY 头像继续复用已有对象及 Key；仅实际创建新对象时生成新格式 Key。
