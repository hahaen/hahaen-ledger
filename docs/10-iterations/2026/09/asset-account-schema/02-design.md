# 设计

采用 `asset_account` 统一主表，使用 `account_type` 的 `FUND`、`CREDIT` 两个代码区分资金账户和信贷账户。统一归属字段、净资产标识、审计和软删除模型有利于资产页聚合查询，也为后续交易表提供统一账户关联点。

金额全部使用整数分：资金账户使用 `balance_cent`，信贷账户使用 `total_limit_cent` 和 `current_debt_cent`。未使用的金额列保持 `NULL`，并由 `CHECK` 约束阻止错误组合。

本轮不拆分两张表，因为两类账户目前共用归属、名称、净资产标识和生命周期，独有字段数量少且可由约束清晰维护。若后续引入分期、利息、手续费或不同生命周期，再重新评估拆分。
