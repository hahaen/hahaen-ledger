# `transaction-refund-modal-design`｜退款弹窗设计对齐

账单详情页退款弹窗按用户提供的视觉参考调整为本系统现有的薄荷绿圆角弹层风格，并修复退款记录删除成功后的页面状态刷新问题。退款删除仍使用既有接口、软删除、金额回算、幂等和权限逻辑。
