# 前端

- `detail.vue` 使用退款专用弹层结构，移除通用弹窗标题栏和关闭按钮。
- `prototype.scss` 增加退款弹层的布局、金额输入框和操作按钮样式，复用现有颜色令牌与安全区规则。
- 打开退款弹窗时将剩余可退款金额以无千分位元文本回填到输入框；确认仍由既有 `refund()` 处理。
- 退款后的详情主金额显示当前有效金额，移除重复的“当前有效金额”独立信息行。
- 退款记录区增加 `REFUND RECORD` 英文眉标题，并使用暖色退款卡片、累计退款汇总行和更清晰的退款明细层级。
- 退款记录删除成功后先按已删除记录回算当前详情，再独立刷新账单和账户；详情刷新失败不会回显旧记录，`saving` 状态始终释放。
- 删除接口失败时将后端返回的真实业务错误展示在确认弹窗内，不再由空 `catch` 吞掉。
- 详情页首次加载由 `onLoad` 在拿到路由账单 ID 后触发；`onShow` 仅在已有详情时刷新，避免生命周期顺序变化时请求空账单 ID。
