# 需求

- 账单详情中的退款弹窗需要与参考图的层级、圆角、拖拽把手、金额输入框和双按钮布局一致。
- 弹窗文案继续展示原账单金额和本次最多可退款金额，并保留退款错误提示与保存中禁用行为。
- 打开弹窗时默认展示当前剩余可退款金额，用户仍可修改并进行部分退款。
- 退款金额不增加货币图标；遵循当前系统金额展示和输入规范。

## 追加需求：退款记录删除闭环

- 点击退款记录“删除”并确认后，退款记录必须从当前详情立即消失。
- 删除成功后账单有效金额、累计退款和退款状态同步更新；刷新失败不能把已成功删除的记录重新显示。
- 删除失败时保留当前记录和确认流程，继续展示接口错误并允许重试。

非目标：不修改退款业务规则、数据库结构、API 路径、幂等键和权限校验。
