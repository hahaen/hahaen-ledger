# 需求

## 目标

扫描当前 `app/src/pages`、`app/src/components`、`app/src/prototype.scss` 和 `app/src/styles.scss`，让 H5 与微信小程序在现有视觉体系下具备一致的按钮显示、文字对齐、页面滚动、小屏适配、弹窗和安全区表现。

## 硬边界

- 不修改接口地址、参数、请求方式、返回结构。
- 不修改现有方法名、业务判断、数据处理和认证逻辑。
- 不重做页面，不改变主题、配色和导航结构。
- 优先使用共享 SCSS；必要的模板改动只能服务于跨端布局。

## 当前发现

- 认证页根容器使用 `overflow:hidden`，小屏或软键盘场景存在内容无法查看的风险。
- 多个弹层使用固定高度或仅使用 `100vh`，底部安全区与动态视口处理不统一。
- 返回、协议链接及部分小型按钮没有统一的 flex 居中和平台默认样式清理。

## 2026-09-17 追加：新增记账页微信小程序顶部控件

- 微信小程序新增记账页的自定义导航不能落入右上角胶囊区域，顶部支出/收入/转账切换按钮不能依赖平台默认高度和行高。
- H5 现有布局、按钮文案、点击事件和记账业务行为保持不变；不修改接口、状态处理和保存逻辑。
