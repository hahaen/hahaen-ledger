# frontend

编辑页仍从账单详情通过 `/pages/entry/entry?id=...` 打开。`loadForEdit()` 回填服务端类型；编辑态不渲染顶部类型切换器，且 `setType()` 在编辑态直接返回。新增态继续渲染并使用三类型切换器。

编辑态标题下方新增只读类型提示，显示“支出记账”“收入记账”“转账记账”或“还款记账”；加载失败或加载中不展示该提示。移除退款提示文案，但保留已有退款账单的类型和账户不可编辑逻辑。

还款类型提示复用账单列表和详情页的还款底色 `#fff4ed`，并使用同一负债色文字。

编辑页放弃修改改为页面内自定义确认弹层，提供“继续编辑”和“放弃修改”两个操作；保存中不可关闭或确认放弃。
