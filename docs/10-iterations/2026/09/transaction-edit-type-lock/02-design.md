# design

编辑页继续以路由 `id` 判断编辑态，并由 `loadForEdit()` 将服务端账单类型写入 `type`。编辑态模板隐藏新增场景的 `entry-type` 切换器，同时让 `setType()` 拒绝编辑态调用，形成视图和状态两层保护。

新增态保持现有三类型切换行为；还款编辑继续由既有类型逻辑处理。

编辑态在标题下方显示只读类型提示“当前账单类型：{类型}记账”，颜色随类型区分；提示仅在编辑数据加载成功后显示，避免把初始默认支出误认为真实类型。

放弃修改使用页面内自定义确认弹层，复用系统圆角弹窗、底部拖拽条、浅色取消按钮和危险色确认按钮，不再调用平台原生 `uni.showModal`。

## 影响

- 前端：`app/src/pages/entry/entry.vue`。
- 测试：补充编辑态类型不可切换、编辑态隐藏类型切换器的静态回归检查。
- 数据库、API、后端：无变化。
