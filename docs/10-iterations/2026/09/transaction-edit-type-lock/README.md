# 编辑记账类型固定

日期：2026-09-09。范围：从账单详情点击“编辑”进入编辑记账时，沿用原账单类型，不再要求用户切换顶部的支出、收入或转账。

本轮仅修改前端交互与回归测试，不修改数据库、后端接口、金额计算和权限逻辑。
