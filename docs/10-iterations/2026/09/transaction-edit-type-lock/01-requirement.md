# requirement

## 来源

- 用户需求：从账单详情点击“编辑”后直接进入对应类型的编辑记账，不需要切换顶部“支出/收入/转账”。
- `哈记账微信小程序_完整功能说明.md` 4.4：点击“编辑”进入回填后的全屏编辑页。

## 验收条件

1. 从详情进入编辑页后，账单类型由接口回填并保持不变。
2. 编辑态不显示新增记账使用的类型切换控件，用户不能误切换类型。
3. 新增记账仍可正常切换支出、收入和转账。
4. 编辑保存仍调用原有更新接口，金额、账户、日期和备注流程不变。
5. 编辑页在标题下方明确显示当前账单类型，例如“收入记账”，且加载完成前不展示未确认的默认类型。
