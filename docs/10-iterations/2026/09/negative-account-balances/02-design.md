# 02｜设计

账单金额始终使用正整数分；交易类型决定账户余额方向。资金账户存储有符号 `balance_cent`，支出、转账转出和还款都可令资金余额低于零。信贷账户仍以 `current_debt_cent` 表示欠款：消费使欠款增加，退款/交易调整可以令欠款低于零；欠款允许超过总额度。负欠款表示账户存在溢缴余额。

支出页面依据类型加载资金与信贷账户，其他原有账户筛选保持不变。后端按账户类型应用流水影响并在同一事务内更新账户。转账和还款不校验资金账户余额；还款金额仍不得超过正向当前欠款。信用卡消费使用当前欠款和总额度计算可用额度，超额时显示非阻断提示。

净资产汇总按符号分解：正资金余额与负信贷欠款计入总资产；负资金余额与正信贷欠款计入总负债。净资产仍为总资产减总负债。

数据库通过 V5 Migration 替换 V3 对账户金额全部非负的检查约束；总额度仍不可为负，但信贷欠款不受额度上限约束。历史 V1–V4 不修改。
