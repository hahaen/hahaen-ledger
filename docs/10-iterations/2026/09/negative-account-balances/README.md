# 负账户余额与信贷支出

## 迭代目的

记账支出允许资金账户余额低于 0，并允许直接记到信贷账户；信用卡超出可用额度时显示超额金额提示，但仍可保存。信贷消费增加欠款，退款或调整可将欠款冲减至负数表示溢缴余额。

## 边界

- 资金账户允许带符号余额，支出不再因余额不足被拒绝。
- 支出账户选择器同时显示资金与信贷账户；信贷欠款允许超过总额度，也允许为负。
- 退款及编辑/删除按账户类型逆转流水；净资产将负资金余额和正信贷欠款计作负债，负信贷欠款计作资产。
- 转账与还款也允许将资金账户扣至负数；收入仍只记入资金账户。超过信用卡可用额度只提示，不阻止记账。
- 真实 MySQL/Flyway、DEV 接口与小程序页面验收单独记录，不以单测或构建代替。
