# 06｜前端

- 新增/编辑支出时，账户选择列表提供资金账户及信贷账户；转账、收入、还款账户列表保持既有类型范围。
- 账户详情的负资金余额和负信贷欠款可编辑并提交，避免读取负值后被前端非负校验拒绝。
- 信贷账户负欠款显示为溢缴余额；还款按钮仅在正欠款时可发起。
- 新增/编辑支出选择信贷账户且金额超出可用额度时显示超额金额提示，不阻止保存；可用额度不足提示会随账户或金额变化更新。
- API 调用仍统一使用 `app/src/utils/api.ts`/现有 store，不直接发起平台请求。
- 前端回归 55 项、TypeScript、H5 构建和微信小程序构建均通过；微信开发者工具/真机交互未运行。
