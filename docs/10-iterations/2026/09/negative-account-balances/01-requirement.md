# 01｜需求与验收条件

## 来源

用户要求记账支出后，信贷账户和资金账户都能体现负向余额，不因资金账户现有余额不足而阻止支出。

## 目标

1. 资金账户余额允许被支出扣至负数。
2. 支出可选择资金账户或信贷账户；信贷支出增加欠款。
3. 退款、编辑和删除正确反向调整资金余额或信贷欠款，信贷欠款可为负以表示溢缴。
4. 资产汇总正确分类账户正负值。

## 保留规则

- 信贷可用额度仍按总额度减当前欠款计算；本次支出超过可用额度时显示超额金额提示，但允许保存，欠款可超过总额度。
- 转账、还款、支出均可使资金账户低于 0；收入仍使用资金账户。
- 当前用户、账户归属、事务、幂等、退款金额上限及逻辑删除行为保持原规则。

## 验收条件

- 后端单测覆盖支出/转账/还款使资金余额低于 0、信贷支出超额度、信贷退款冲至负数；前端覆盖可用额度超额提示金额计算。
- 前端支出账户列表包含资金与信贷账户，收入/转账/还款仍仅展示适用账户。
- Flyway 新迁移可表达资金余额及信贷欠款的有符号值，不修改 V1–V4。
- 资产汇总将透支资金和正信贷欠款计入负债，将负信贷欠款计入资产。
- 代码、API/数据库规范、功能说明、迭代与审计记录同步。
