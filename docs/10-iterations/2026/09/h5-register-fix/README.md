# `h5-register-fix`｜H5 注册路由回归修复

## 这次迭代解决什么问题

本次是一次小范围前端回归修复，针对直接打开注册页时页面被启动重定向覆盖，以及密码公钥接口路径不一致导致注册提交报错的问题。目标是恢复注册页的可访问性，同时保持既有认证协议和数据库结构不变。

## 变更边界

- 只调整 `App.vue` 的 H5 路由判断和 `passwordCrypto.ts` 的公钥请求路径。
- 后端 Controller、注册接口、数据库结构、密码协议和其他业务不在变更范围内。
- 测试不自动提交注册表单，避免创建测试账号；因此真实账号落库和验证码消费仍需另行验证。

## 文件怎么读

`01`–`06` 分别说明需求、设计、数据库、API、后端和前端影响；`07` 记录路由、公钥和构建检查；`08` 是真实命令；`09` 给出根因和回归证据；`10` 列出可恢复的代码文件。

## 结论边界

通过路由回归和构建只能证明页面入口与调用路径已修复，不能推导出完整注册链路已在真实数据环境通过；需要以 `09-verification.md` 中列出的证据范围为准。
