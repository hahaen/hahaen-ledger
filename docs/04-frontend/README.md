# 04｜前端规范与现状

本目录是 Vue 3 + TypeScript + uni-app 的页面与交互约束入口。当前构建目标包括 H5 和微信小程序，但“可构建”不等于两端认证和真实依赖链路均已闭环。

## 代码位置

- 页面放在 `app/src/pages`，当前页面包括认证、首次使用、首页、日历、资产、记账、账单详情、账户详情、我的和帮助；小程序默认首路由为首页，首次使用页保留为可选页面。
- 跨页状态放在 `app/src/stores/ledger.ts`，复用 UI 放在 `app/src/components`。
- 业务请求统一经 `app/src/utils/api.ts`；头像上传经 `app/src/utils/file.ts`，页面不得直接拼接后端请求或 MinIO 凭证。
- H5 头像上传在 `utils/file.ts` 先校验 10MB 限额、以文件头识别 JPEG/PNG/WebP/GIF 实际类型并计算 SHA-256，再申请上传授权；不信任扩展名或浏览器 MIME。后端返回 `READY` 时直接取既有短时预览地址，禁止重复 PUT 同一图片。
- `pages.json` 的底部导航固定为：首页、日历、资产、物品、我的。记账、详情和账户详情是二级页面。
- `BottomNav` 必须使用五项等宽的连续底栏；五项图标按可见轮廓对齐，字符图标分别按字形留白调整字号，首页和日历的字形向上微调 2px，物品描边图标适当收小，不再额外缩放。导航按钮显式清除平台默认边框、圆角、阴影和背景，仅当前项图标使用选中态薄荷绿背景。
- 微信平台差异使用条件编译；小程序登录分支调用 `uni.login` 后请求 `/api/app/auth/wechat-mini/login`，H5 继续使用账号密码认证。
- 微信小程序的全部路由页面在独立 `<script lang="ts">` 中显式声明 `onShareAppMessage: createWechatShareMessage`，共享 `utils/wechatShare.ts` 的固定标题、首页路径和服务器启动页文案图（`staticResource('share-welcome.png')`，500×400，公开HTTPS地址）。分享回调直接返回网络图片，不调用本地文件API；原图备份在 `app/offloaded-static-assets/wx/share-welcome.png`，不再打入代码包。图片服务须公开可读且可用；不携带账单或用户参数。H5 条件编译排除微信分享选项。禁止只依赖全局 mixin：uni-app 一次性读取 App mixin，页面先注册时可能永久遗漏回调；也不能在工具函数中间接注册 setup 回调。新增页面须同步接入，并执行源码原生生命周期回归及生产包检查 `node app/tests/wechat-share-build.check.mjs`（先构建微信产物）。朋友圈本轮未开放。
- 新增/编辑记账页的主体内容由 `.entry-content` 独立滚动，数字键盘保持固定；H5 明确使用 `flex:1 1 0`、`height:0`、`overflow-y:auto` 和 iOS 惯性触摸滚动，避免手机视口下 flex 子项无法触摸上滑；主体使用 `@touchmove.stop` 阻止事件冒泡至 H5 的 `disableScroll` 全局监听，但不取消默认滚动。

## 自定义导航与微信胶囊对齐

所有显示自定义页头的微信小程序页面共用 `components/NativeNavigation.vue`：品牌页头、返回/标题栏和帮助类标题均读取 `uni.getMenuButtonBoundingClientRect()`，按胶囊实际 top/height 布局；主导航页品牌图标与标语在同一水平行。顶部状态栏和安全区留白取较大值，不相加。H5 保留原页头排列与尺寸。首次使用页沿用相同的小程序胶囊定位；登录/注册内容区仍按认证页设计留白。

## 当前已落地页面能力

首页支持月度汇总、日期分组账单、空态和重试；最近记账首段包含当前月和上月，记录区触底后以月份游标继续追加更早的两个月，摘要仍只计算当前月；内容不足以触发滚动时保留“加载更多账单”按钮作为同一游标的回退入口；日历支持 42 格月历、月份切换和单日列表，顶部页头固定，月历、当月汇总、日期标题和全部账单共用一个原生 scroll-view，账单自然展开；资产支持账户分组、净资产概览、账户 CRUD、流水筛选、信贷还款和同类账户长按换序，资金账户和信贷账户详情固定账户信息、流水标题及五项筛选按钮，仅日期和流水区域独立滚动，日期分组标题按组吸顶；记账支持支出/收入/转账和金额计算器；详情支持编辑、删除、支出/收入退款及退款记录删除；我的页支持 H5 头像上传、个人资料和注销，个人中心、关于与帮助和退出登录均使用相同的设置按钮行；帮助页的导出/删除、反馈等仍是明确的占位入口。

## 交互约束

按钮及明确可点击控件通过 prototype.scss 提供两端一致的微小按压缩放，不触发系统振动。金额键盘按键单独保留轻振动：支持标准 API 的 H5 浏览器调用 navigator.vibrate(15)，微信小程序调用 uni.vibrateShort({ type: 'light' })；禁用按键不触发。iPhone Safari 原生 switch 适配与验收限制见下文，不启用全局振动。

金额格式统一使用 app/src/utils/money.ts：formatYuan() 接收整数分并返回不带货币符号的文本。运行时页面的可视金额统一使用 app/src/components/MoneyDisplay.vue，组件只展示金额数值和必要的正负/文字前缀，不渲染钱币图标；金额输入框同样不附加 ¥。整数金额不展示 .00，有效小数保留两位，数字/字符串/null/undefined 输入必须得到一致且安全的结果。页面禁止自行调用 toFixed、判断 .00 或通过 /100 拼接展示金额。

保存、退款、还款、删除和上传类操作必须有 loading/禁用态，成功后刷新受影响的首页、日历、账户和资产状态，失败后保留可重试路径。金额使用整数分传输；页面金额输入最终必须通过 `utils/money.ts` 转换，不能使用浮点值作为持久化口径。账户名最多 20 个字符，备注最多 100 个字符。

登录页和注册页共用 `components/AuthPage.vue`；账号仅允许 2–64 位英文字母或数字，输入时应移除中文、空格和符号；密码输入框右侧必须提供可点击的小眼睛控件，用于在密码掩码和明文之间切换，并通过 `aria-label`/`title` 说明当前操作。

涉及确认退出、删除或放弃编辑的页面不得使用平台原生确认框，应复用项目的自定义圆角确认弹层：半透明遮罩、顶部提示条、白色圆角面板和取消/确认双按钮。提交期间必须禁用关闭和重复提交操作。我的页退出登录复用该规范；H5 退出后回到登录页并由全局守卫禁止访问业务页，微信小程序保持平台登录流程。

认证页只展示账号、密码、图形验证码、协议勾选与主操作入口，不展示微信自动登录或注册资料说明文字；登录和注册均须在提交前勾选同意《用户协议》《隐私协议》，两份协议必须可在未登录状态阅读；微信小程序自动登录由平台启动流程处理。

生产构建不允许通过大面积 `any`、关闭 strict、`eslint-disable` 或 `@ts-ignore` 掩盖类型问题。视觉截图或浏览器运行证据必须实际存在；没有截图文件时不能把设计验收写成 PASS。

H5 浏览器入口统一在 `app/index.html` 声明 `/static/brand.png` 为 PNG favicon，主屏幕 `apple-touch-icon` 复用 `/offloaded-static-assets/wx/brand-white.png` 白底品牌源图。两者均由 Vite 解析存在的源文件并生成带 `/haji/` base 与内容哈希的资源，禁止引用已删除的 `/static/brand-white.png`；不在页面组件中各自维护图标。H5 构建后执行 `node app/tests/h5-icons-build.check.mjs`（仓库根目录），验证实际生产 HTML、图标 HTTP 状态、PNG 类型及与源图一致。白底图不重新放入小程序 static 目录，修复仅需发布完整 H5 静态产物。真机主屏幕图标须在发布后重新添加验收，详见[本轮档案](../10-iterations/2026/10/h5-home-screen-icon/README.md)。

## 个人中心（2026-09-11）

“我的”页顶部头像是纯展示元素，点击无任何响应；不跳转个人中心、不预览，也不提供更换照片入口。设置列表中的个人中心入口仍进入 `pages/profile/profile`。资料页顶部返回始终切换到“我的”页，不依赖页面历史栈。资料页使用既有头像上传工具、当前用户资料接口和自定义圆角弹层；选择新头像并完成文件上传后，页面立即使用该文件的短时 `viewUrl` 作本地预览，但只暂存文件 ID，不调用资料更新接口或变更当前用户头像字段；点击保存时才随 `avatarFileId` 提交并在资料事务中关联。保存资料前，头像、昵称、账号在前端均为必填，昵称/账号/密码另有长度和格式校验，保存与密码提交期间均禁用重复操作。未设置密码时，账号下方显示首次密码框并随保存请求一起设置；已设置密码时隐藏该框、显示修改密码按钮。两处密码输入均复用登录页的小眼睛显隐控件。资料保存成功后显示不可关闭的成功弹层 0.5 秒，随后自动返回“我的”页。

个人中心两处密码提交都保持 RSA-OAEP（SHA-256）密文协议。H5 使用浏览器 Web Crypto；微信小程序缺少 Web Crypto 时，由平台工具层使用微信密码学安全随机数和兼容 RSA 实现生成同规格 `encryptedPassword`，不得降级为明文或弱随机数。

“我的”页在“个人中心”下方增加“通知中心”设置行，进入独立页面 `pages/notification-center/notification-center`。Bark 与 pushplus 两个通知 Key 均为选填，不使用密码显隐小眼睛；页面每次进入加载当前用户配置并回显已有 Key，不在本地存储缓存。清空字段并保存即移除对应配置，未修改字段不提交；保存期间输入与按钮禁用，失败保留输入和原幂等请求以重试，成功保留回显值并更新已保存基线。页面顶部复用个人中心的 `profile-hero` 薄荷渐变引导卡，显示“通知中心”标题与配置说明，表单保留公共 20px 卡片间距；其余使用现有二级页头、白卡片、薄荷绿输入与保存按钮，经 `api.ts` 调用接口，注册统一微信转发。

头像资料中的 `avatarFileUrl` 是稳定对象 Key，仅用来判断是否有已配置头像；实际 `<image>` 永远使用后端返回的短时 `viewUrl`，因此 MinIO 域名前缀变更不影响已保存头像。

uni-app H5 会把模板 `input[type=file]` 编译为普通文本输入，头像入口必须在用户点击手势中动态创建浏览器原生 `input[type=file]`，绑定既有选择回调后再点击；不得使用全局 DOM 选择器或模板文件 input。

## 核心页面交互补充（2026-09-08）

金额展示使用 formatYuan，编辑/退款输入使用 inputYuan，禁止把千分位分隔符送入金额校验。账户余额和欠款允许显示负数；支出账户选择支持资金及信贷账户，支出超过信用卡可用额度时显示超额金额提示但仍允许保存；收入、转账和还款继续按适用类型筛选。新增/编辑加载失败时禁写；成功后的刷新失败应提示刷新失败，不得诱导重复创建。日历保存选中日期并拒绝过期日请求，新增入口传递该日期。还款详情支持编辑，转出使用资金账户、目标使用信贷账户；已有退款时锁定类型和账户。详见 [本次迭代](../10-iterations/2026/09/negative-account-balances/README.md)。

## 物品页（2026-09-28）

items一级页位于资产右侧，item-detail为二级页。物品清单行左侧显示名称、实际净成本/日均成本和购入时间，右侧突出显示服役天数；在役净成本等于购入价，退役净成本扣除二手售价，可为负数。退役物品行使用灰色底色，在役物品行保持白色。通过api.ts的itemApi调用，独立items.ts类型/日期/金额校验，不改变ledger记账状态。ItemEditor复用CenterModal创建/退役；ItemProfileEditor编辑名称、购买价格和日期，保存失败保留数据及同一幂等键，修改请求内容则更换键。ItemCostChart采用uni canvas、日期等距横轴、人民币/天纵轴，最多31个历史采样点，resize时重绘。列表onShow刷新，筛选和分页响应序列保护；失败重试保持原分页操作。详情加载失败不显示操作按钮。

已退役物品详情显示“重新服役”，确认层说明会清空退役日期和二手出售价格；确认时按钮进入加载/禁用态，失败保留确认层及幂等键以重试。成功后刷新详情，显示在役成本；返回清单时由 onShow 刷新汇总。

购买、退役、物品资料编辑及记账日期共用 `EntryDateTimePicker`：年份滚轮完整显示 2000–2099，默认当天；各列首尾留白使所选年、月、日保持居中。显示年份范围不改变业务可保存范围，物品日期仍不晚于当天，退役和编辑仍受已有日期先后关系约束；弹窗确认前阻止超出调用方 `minDate/maxDate` 的日期。

物品新增和资料编辑的购买价格输入框以 `0` 占位；资料编辑使用 `inputYuan` 回显整数分，整元不显示 `.00`，有角分保留两位，且不带千分位分隔符。

## 微信小程序启动兼容（2026-09-28）

## 2026-10-25 iPhone Safari 金额键盘触感

仅 H5 记账金额键盘使用 CalculatorKey；检测 iPhone Safari 和原生 switch 支持后，以真正 HTML checkbox switch 的透明覆盖层接收手指点击。原生 input 由 Vue h 创建，避免 uni-input 转换；与可读屏/键盘操作的原按钮同级，覆盖层 aria-hidden 且不进入 Tab 顺序。所有路径仍只调用一次 pressCalculatorKey，加载/保存/错误禁用时覆盖层也 disabled；减少动态效果时覆盖层不捕获点击。微信条件编译完全排除组件与 DOM 探测，保留原按钮和反馈。
