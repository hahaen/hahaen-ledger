# 04｜前端规范与现状

本目录是 Vue 3 + TypeScript + uni-app 的页面与交互约束入口。当前构建目标包括 H5 和微信小程序，但“可构建”不等于两端认证和真实依赖链路均已闭环。

## 代码位置

- 页面放在 `app/src/pages`，当前页面包括认证、首次使用、首页、日历、资产、记账、账单详情、账户详情、我的和帮助。
- 跨页状态放在 `app/src/stores/ledger.ts`，复用 UI 放在 `app/src/components`。
- 业务请求统一经 `app/src/utils/api.ts`；头像上传经 `app/src/utils/file.ts`，页面不得直接拼接后端请求或 MinIO 凭证。
- `pages.json` 的底部导航固定为：首页、日历、资产、我的。记账、详情和账户详情是二级页面。
- 微信平台差异使用条件编译；当前小程序登录分支调用 `/api/app/auth/login`，但后端没有该路由，属于待闭环问题。

## 当前已落地页面能力

首页支持月度汇总、日期分组账单、空态和重试；日历支持 42 格月历、月份切换和单日列表；资产支持账户分组、净资产概览、账户 CRUD、流水筛选和信贷还款；记账支持支出/收入/转账和金额计算器；详情支持编辑、删除、支出/收入退款及退款记录删除；我的页支持 H5 头像上传、个人资料和注销；帮助页的导出/删除、反馈等仍是明确的占位入口。

## 交互约束

保存、退款、还款、删除和上传类操作必须有 loading/禁用态，成功后刷新受影响的首页、日历、账户和资产状态，失败后保留可重试路径。金额使用整数分传输；页面金额输入最终必须通过 `utils/money.ts` 转换，不能使用浮点值作为持久化口径。账户名最多 20 个字符，备注最多 100 个字符。

生产构建不允许通过大面积 `any`、关闭 strict、`eslint-disable` 或 `@ts-ignore` 掩盖类型问题。视觉截图或浏览器运行证据必须实际存在；没有截图文件时不能把设计验收写成 PASS。
