# 04｜前端规范与现状

本目录是 Vue 3 + TypeScript + uni-app 的页面与交互约束入口。当前构建目标包括 H5 和微信小程序，但“可构建”不等于两端认证和真实依赖链路均已闭环。

## 代码位置

- 页面放在 `app/src/pages`，当前页面包括认证、首次使用、首页、日历、资产、记账、账单详情、账户详情、我的和帮助。
- 跨页状态放在 `app/src/stores/ledger.ts`，复用 UI 放在 `app/src/components`。
- 业务请求统一经 `app/src/utils/api.ts`；头像上传经 `app/src/utils/file.ts`，页面不得直接拼接后端请求或 MinIO 凭证。
- `pages.json` 的底部导航固定为：首页、日历、资产、我的。记账、详情和账户详情是二级页面。
- `BottomNav` 必须使用四项等宽的连续底栏；导航按钮显式清除平台默认边框、圆角、阴影和背景，仅当前项图标使用选中态薄荷绿背景。
- 微信平台差异使用条件编译；当前小程序登录分支调用 `/api/app/auth/login`，但后端没有该路由，属于待闭环问题。

## 当前已落地页面能力

首页支持月度汇总、日期分组账单、空态和重试；日历支持 42 格月历、月份切换和单日列表，页头、月历、日汇总与日期标题固定，仅选中日期的记账记录区域独立滚动；资产支持账户分组、净资产概览、账户 CRUD、流水筛选、信贷还款和同类账户长按换序，资金账户和信贷账户详情固定账户信息、流水标题及五项筛选按钮，仅日期和流水区域独立滚动，日期分组标题按组吸顶；记账支持支出/收入/转账和金额计算器；详情支持编辑、删除、支出/收入退款及退款记录删除；我的页支持 H5 头像上传、个人资料和注销；帮助页的导出/删除、反馈等仍是明确的占位入口。

## 交互约束

金额格式统一使用 app/src/utils/money.ts：formatYuan() 接收整数分并返回不带货币符号的文本。运行时页面的可视金额统一使用 app/src/components/MoneyDisplay.vue，组件只展示金额数值和必要的正负/文字前缀，不渲染钱币图标；金额输入框同样不附加 ¥。整数金额不展示 .00，有效小数保留两位，数字/字符串/null/undefined 输入必须得到一致且安全的结果。页面禁止自行调用 toFixed、判断 .00 或通过 /100 拼接展示金额。

保存、退款、还款、删除和上传类操作必须有 loading/禁用态，成功后刷新受影响的首页、日历、账户和资产状态，失败后保留可重试路径。金额使用整数分传输；页面金额输入最终必须通过 `utils/money.ts` 转换，不能使用浮点值作为持久化口径。账户名最多 20 个字符，备注最多 100 个字符。

登录页和注册页共用 `components/AuthPage.vue`；密码输入框右侧必须提供可点击的小眼睛控件，用于在密码掩码和明文之间切换，并通过 `aria-label`/`title` 说明当前操作。

认证页只展示账号、密码、图形验证码和主操作入口，不展示微信自动登录或注册资料说明文字；微信小程序自动登录由平台启动流程处理。

生产构建不允许通过大面积 `any`、关闭 strict、`eslint-disable` 或 `@ts-ignore` 掩盖类型问题。视觉截图或浏览器运行证据必须实际存在；没有截图文件时不能把设计验收写成 PASS。

H5 浏览器入口统一在 `app/index.html` 声明 `/static/brand.png` 为 PNG favicon，复用主应用图标；不在页面组件中各自维护浏览器图标资源。

## 核心页面交互补充（2026-09-08）

金额展示使用 formatYuan，编辑/退款输入使用 inputYuan，禁止把千分位分隔符送入金额校验。新增/编辑加载失败时禁写；成功后的刷新失败应提示刷新失败，不得诱导重复创建。日历保存选中日期并拒绝过期日请求，新增入口传递该日期。还款详情支持编辑，转出使用资金账户、目标使用信贷账户；已有退款时锁定类型和账户。详见 [本次迭代](../10-iterations/2026/09/core-pages-prototype/README.md)。

## 首页交互修正（2026-09-08）

首页“当前年/月 · 日均消费”为普通文字，不提供月份选择；最近记账右侧不显示刷新按钮。年月与查询范围在加载时按当前日期更新。类型检查、H5 构建 PASS。档案：docs/10-iterations/2026/09/home-static-month/README.md。
