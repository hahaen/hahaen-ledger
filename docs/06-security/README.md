# 06｜安全规范

本目录集中说明认证、授权、数据归属、文件访问和敏感信息保护规则。安全检查必须结合代码、数据库约束、日志和实际接口行为进行，不能只看前端是否隐藏了按钮。

## 核心控制点

- 认证使用 Sa-Token 当前会话；业务查询必须同时过滤当前用户和当前账本。
- 账户、账单、退款和文件必须做服务端归属校验，防止 IDOR；名称快照只能展示，不能用于权限判断。
- 密码只保存安全哈希；验证码、会话和绑定凭证放在有 TTL 的 Redis 或认证模块中。
- MinIO 不向小程序暴露密钥或永久 URL，文件预览和删除都要在后端鉴权。
- Redis Key 统一以 `haji:` 开头，不含环境名，不执行 `FLUSHALL`/`FLUSHDB`。

## 审查方式

新增接口时同时检查未登录、跨用户、跨账本、逻辑删除对象、重复提交和异常日志场景；发现真实凭证进入代码、文档、命令或日志时，应立即隔离并记录整改。
