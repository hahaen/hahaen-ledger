# 哈记账｜微信小程序原型设计稿

这是《哈记账微信小程序_AI设计稿需求.md》的移动端高保真交互原型，基准画布为 375 × 812 px。直接打开 `index.html` 即可预览；桌面端展示手机画布，窄屏自动铺满。

## 这版优化了什么

- 全部品牌命名统一为“哈记账”，接入目录中的 `../哈记账.png` 作为品牌标识和头像默认图。
- 第一版导航固定为：首页、日历、资产、我的；统计只在设计说明中预留，不作为可用入口。
- 首页首屏固定展示“日均消费”和“本月支出”，账单按日期分组，收入、支出、转账使用文字标签区分。
- 新增/编辑记账保持全屏流程；账户、日期和备注使用在屏幕中央展示的选择器/短任务弹窗。
- 转账明确拆分“转出账户”和“转入账户”，并校验两者不能相同。
- 金额计算器支持 `+`、`−`、`×`、`÷`、小数点、清除、退格、等号、两位小数和除数为 0 错误；按标准优先级计算。
- 记账不设置分类和账单凭证，新增记账默认沿用上一次保存时使用的账户，日期与时间默认取设备当前本地时间。
- 金额键盘采用四列四行布局，固定贴在记账页面底部，内容区域可独立滚动。
- 头像授权支持未授权、授权中、授权成功三个可操作状态；拒绝授权不影响记账。
- 修复月份选择器点击无响应的问题，并补齐按钮语义、触控区域和键盘输入限制。

## 页面与状态映射

| 页面/入口 | 默认态 | 关键交互与状态 |
| --- | --- | --- |
| 首页 | 2026 年 9 月示例数据 | 账单进入编辑、右下角 `+` 新增记账 |
| 新增记账 | 空金额、支出 | 三种类型、计算器、账户/日期/备注、保存中/成功 |
| 编辑记账 | 回填午餐 ¥32.00 | 修改、删除确认、未保存退出确认 |
| 日历 | 2026 年 9 月 | 月份切换、年月选择、日期选择、当天收入/支出/结余、账单编辑 |
| 资产 | 净资产/总资产/总负债 | 资金账户和信贷账户分组、新增账户、编辑账户、余额只读说明 |
| 我的 | 头像未授权 | 授权反馈、累计记账 28 日、账户管理跳转、暂不开放提示 |
| 首次使用 | 设计说明面板内预览 | “开始记账”和“稍后设置账户”，不强制头像授权或账户初始化 |

## 预览方式

1. 打开 `index.html`。
2. 点击任意账单进入编辑页；点击右下角 `+` 进入新增记账。
3. 在新增/编辑页点击类型切换、账户、日期和备注，检查屏幕中央的短任务弹窗；保存一笔后再次新增，检查账户和当前日期时间默认值。
4. 点击右上角“标注”，可查看设计令牌并预览首次使用页。

## 设计令牌

- 页面背景 `#F7F8F7`，卡片 `#FFFFFF`
- 主色 `#49AD9C`，按压/深色 `#278879`，浅色背景 `#DFF2EF`
- 主要文字 `#171A1A`，次要文字 `#858B8B`，辅助文字 `#B0B5B4`
- 收入 `#FF5B5B`，支出 `#278879`，负债 `#E58A5B`
- 页面左右边距 16px，模块间距 12–24px，卡片圆角 14–20px
- 触控目标不小于 44px；底部导航和悬浮按钮避开安全区与最后一条账单

## 业务口径

- 统计按用户本地时间和自然月计算；金额为人民币元，精确到 0.01 元。
- 支出：资金账户余额减少，信贷账户欠款增加；收入：资金账户余额增加；转账：转出减少、转入增加，且不进入收支统计。
- 净资产 = 总资产 − 总负债；信贷账户使用“当前欠款”表达，不显示负数负债。
- 删除有历史流水的账户应停用而非物理删除；编辑账户不能直接改余额，余额由期初余额和流水计算。

## 文件服务边界

凭证和头像由 Java 后端鉴权并管理元数据，MinIO 只存储二进制对象。小程序端只调用业务接口和短时效上传/预览 URL，不拼接 MinIO 地址、不保存永久 URL、不接触 Access Key/Secret Key。

首版支持 JPG、JPEG、PNG、WEBP；单张建议 ≤ 10MB，单笔最多 9 张凭证，头像最多 1 张。上传流程为“前端校验 → 获取授权 → 上传 → 后端确认 → 关联账单”，失败、URL 过期、网络异常和对象清理均需可重试。

## 320 / 375 / 414 px 适配

- 320px：左右边距仍为 16px；长名称省略或换行，金额不截断，计算键盘保持四列。
- 375px：基准画布；摘要卡片、日历、账单列表和底部导航按设计稿展示。
- 414px：仍保持单列内容；悬浮按钮固定在安全区内，不遮挡最后一条账单。
- 所有宽度禁止横向滚动；底部导航预留 `env(safe-area-inset-bottom)`。
